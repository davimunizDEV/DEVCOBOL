Projeto COBOL

Repositório criado para documentar meus estudos e minha evolução no desenvolvimento com COBOL, explorando conceitos fundamentais da linguagem e práticas comuns em ambientes Mainframe.

📚 Sobre o projeto

Este projeto reúne programas desenvolvidos durante meus estudos de COBOL, com foco em compreender a estrutura da linguagem, processamento de arquivos e conceitos relacionados ao ecossistema Mainframe.

Entre os conceitos estudados estão:

Estrutura de programas COBOL
Divisions e Sections
Variáveis e níveis de dados
PIC e tipos de dados
PERFORM
Condições e loops
Manipulação de arquivos
Sequential Files
Copybooks (COPY)
JCL e execução de programas
Códigos de retorno (RETURN-CODE)
Tratamento de arquivos e registros
Conceitos de processamento Batch
🛠️ Tecnologias
COBOL
GnuCOBOL
Visual Studio Code
Windows
🎯 Objetivo

Meu objetivo com este repositório é consolidar meus conhecimentos em COBOL e Mainframe através de projetos práticos, acompanhando minha evolução desde os fundamentos até conceitos mais avançados
